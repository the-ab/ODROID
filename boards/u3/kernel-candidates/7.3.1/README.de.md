# Linux-7.3.1-Kandidat für U3

[English](README.md)

Explizites Profil für die signaturgeprüften Linux-7.3.1-Quellen. Das vorliegende 1.0.1-Imagerezept behält seinen abgenommenen 6.12.114-Kernel. Fünf Boardänderungen werden portiert; die ausführliche Device-Link-Diagnose ist bereits upstream. Native APT-/Boot-/Rückfalltests und aktuelle CVE-Prüfung werden getrennt dokumentiert. Die getesteten Binärpakete 7.3.1-1 und 6.12.114-1 wurden am 30.10.2026 ausdrücklich zur Veröffentlichung freigegeben; siehe [APT-Anleitung](../../../../docs/KERNEL-UPDATES.de.md).
