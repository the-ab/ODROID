# Linux 7.3.1 U3 candidate

[Deutsch](README.de.md)

Explicit profile for the signed Linux 7.3.1 source. The default 1.0.1 image recipe remains on its accepted 6.12.114 kernel. This candidate ports the five board-specific source changes; the extended device-link diagnostic is already upstream. Native APT/boot/rollback and current CVE checks are tracked separately. The tested 7.3.1-1 and 6.12.114-1 binaries were explicitly approved for publication on 30 October 2026; see the [APT guide](../../../../docs/KERNEL-UPDATES.md).
