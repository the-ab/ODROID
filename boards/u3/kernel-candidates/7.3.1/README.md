# Linux 7.3.1 U3 candidate

[Deutsch](README.de.md)

Explicit profile for the signed Linux 7.3.1 source. The default 1.0.1 image recipe remains on its accepted 6.12.114 kernel. This candidate ports the five board-specific source changes; the extended device-link diagnostic is already upstream. Native APT/boot/rollback and current CVE checks are tracked separately. No stable binary publication is implied.
