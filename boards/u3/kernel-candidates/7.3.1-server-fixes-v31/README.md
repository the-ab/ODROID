# Combined U3 server fixes, revision31

[Deutsch](README.de.md)

This candidate combines the unchanged v30 GIC RAM-counter accessor correction and seven io_uring fixes with four reviewed v7 audio/USB changes: stream-specific Samsung DMA allocation, the physical microphone/backend route, playback-only HDMI capability and optional USB PHY VBUS acquisition with real errors propagated. The upstream secondary I2S topology is retained; no added parent relationship.

V30 passed its transition and three diagnostic warmboots, then one normal release-argument boot without diagnostic output. That normal boot still reproduced the old RX-DMA and missing-VBUS warnings because the isolation baseline had not incorporated the audio/USB fixes. The boot qualification below therefore uses this complete candidate. No new register masks, secure/debug/firmware changes, forced IRQ count or global JUMP_LABEL disable. All XFS/server capabilities remain. Source/build/package, native acceptance and physical microphone/display acceptance stay separate. V25 remains the exact direct rollback, v17 the reserve. No release acceptance.

The24-file pinned-source replay, ARM build,101-capability gate and actual C resource/compiled-DT audio graph checks pass. The DTB is byte-identical to functionally tested v7. Configuration changes only LOCALVERSION; the package and351 module checks pass.

On2026-11-05, this exact binary passed its first normal boot, then10 pure warmboots and5 controlled halt/cold starts on native eMMC. Diagnostic boot flags were disabled. Every boot had four advancing CPU timers,351 matching module hashes, no kernel-error journal entries, no failed services, audit loss0 and taint0. The old I2S RX-DMA allocation and missing USB-VBUS warnings were absent. Each cold start followed a UART-confirmed halt and at least10 seconds of independently read-back power OFF. Complete UART intervals and health/power receipts were hash-checked privately.

The wrong original GIC-base access was captured in v29; the precise text-patch/instruction-cache mechanism remains unproven. These bounded boot results qualify the tested correction under normal arguments, not indefinite reliability. Final server/io_uring/audio-DMA regression, fresh images, firmware distribution coverage and applicable human first-boot/peripheral acceptance remain separate open gates. No public binary/APT/Main promotion.

The subsequent native server batch completed its application/data assertions, including Docker29, WireGuard/OpenVPN, IPv4/IPv6 filtering, SMB/CIFS/NFS/SSHFS, AppArmor/Landlock/audit and internal stereo codec loopback. However, the normal OpenVPN path emitted an ARM32 TUN statistics lockdep warning and disabled lockdep checking. This rejects final qualification even with taint0 and an empty error-priority journal. An actual deadlock was not observed. The isolated NFS fixture also omitted nfsdcld; its recovery warning must be addressed separately. Ordinary io_uring and additional real HSIC transfer checks remain open. See the targeted [v32 candidate](../7.3.1-tun-stats-v32/README.md); no new images or release acceptance.
